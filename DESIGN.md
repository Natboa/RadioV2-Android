# Design System: RadioV2 Android

## Overview

**Creative North Star: "Quiet library, expressive player"**

The station library is calm and easy to scan. Existing genre sleeves provide the rich colour and texture. The interface uses neutral tonal layers, strong headings, and deliberate separation between sections. Android controls, system Back and touch conventions remain familiar.

The player has its own focus: a compact dock preserves space for station names, while shared artwork and a short upward transition connect it to expanded playback. No simulated audio visualization runs at rest.

**Key Characteristics:**
- Existing square artwork, contained and decoded at its display size.
- Magenta-derived functional accents on neutral light and dark surfaces.
- Foreground-coloured favourite hearts.
- Lazy shelves, readable rows and quick search.

## Colors

The identity seed is magenta; Flutter's vibrant Material tonal scheme supplies accessible foreground/container pairs. `lib/core/designsystem/theme.dart` owns the implemented roles; `colors.dart` contains only the seed. Exact extracted values are in `build/design/tokens.json`, generated by the token export tool.

Light primary/onPrimary: #B60077/#FFFFFF. Dark primary/onPrimary: #FFAFD2/#63003F. Light primaryContainer/onPrimaryContainer: #FFD8E7/#8B005A; dark: #8B005A/#FFD8E7.

Neutral surfaces progress from #FAF8F9 through #F3F0F2 to #E7E3E6 in light mode; from #121215 through #1B1B1F to #2B2B30 in dark mode. Text uses onSurface and onSurfaceVariant, never a widget-local fixed colour.

**The Content Colour Rule.** Genre artwork keeps its original colours. UI accent appears on primary playback, selection, focus and connection status. Favourite hearts use onSurface in both saved and unsaved states.

**The Recoverable Station Rule.** An unavailable station receives a compact neutral message with Retry and a calm inline player state. Error colours remain available for actual errors.

## Typography

Android's Roboto face and Material text scale provide native readability. App bars and player titles use headlineMedium (28sp, weight700, tracking-0.7). Shelf and section headings use titleLarge (22sp, weight700, tracking-0.4); station rows use titleSmall (14sp, weight600). Body roles remain14/16sp; supporting text uses bodySmall12sp.

**The Full Name Rule.** Rows allow two lines and the expanded player allows three. Truncation preserves accessible names. Text scaling is never clamped; short screens can scroll the player.

## Layout

24dp content gutters; 12dp outer row margins and dock margins. Related controls sit8–16dp apart; section boundaries get24dp or more. Compact widths use a three-destination navigation bar. Widths700dp and above use a navigation rail. Keyboard focus hides the bottom dock/navigation while searching.

Discover uses a lazy vertical builder containing lazy horizontal shelves. The search grid uses2–5 columns based on available width, with text-scaled cell height. Artwork always has equal width and height. No eager group-widget maps, shrink-wrapped catalogues or whole-catalogue image precaching.

The mini-player participates in Scaffold bottom layout rather than covering list content. Floating notifications sit above it. Expanded playback pins controls above system insets while artwork and station details scroll independently; it changes to a two-column composition at700dp.

## Elevation & Depth

Tonal layering supplies depth: surface for the page, surfaceContainerLow for search/settings, surfaceContainerHigh for the dock and logo fallback. No repeated blur, glass, gradient wash or per-item shadow. Material elevation is reserved for transient overlays.

## Shapes

Genre art and row logos use12dp corners, station selection18dp, the dock22dp and expanded artwork28dp. Search fields use18dp with a visible1.5dp primary focus border. Play controls are circular and keep48dp minimum touch targets.

## Components

- **Station rows:** keyed by station ID, contained cached logo48dp, two-line title, optional selected/playing subtitle, foreground favourite toggle with explicit save/remove tooltip.
- **Missing station artwork:** neutral initials tile, consistent across rows, dock and player; also used while loading or after an image failure. Initials are decorative, grapheme-safe and fitted to the tile; accessible station names remain complete. Retain real logos without tinting them.
- **Group ordering:** featured stays pinned. Ordinary results place supported artwork URLs ahead of missing, unsupported and previously confirmed failed images, with name/ID tie-breaks. One failure-metadata snapshot is frozen for all pages/search during a visit; rows never disappear or move after an image error. Closing the group releases that snapshot; the next open/explicit retry adopts newer metadata. No preflight network checks.
- **Artwork health:** ordinary image requests learn HTTP403/404/410 and decoder failures for six hours, capped at256 URLs. Metadata is non-reactive and persisted using already-loaded preferences. Offline, timeout, DNS and server failures do not classify a logo as missing. Newly encountered failures keep their current position until the next visit.
- **Genre sleeves:** square, contain fit, decode dimensions derived from display size × pixel ratio. Text labels remain outside the image.
- **Search:** shared controller-aware clear action, search keyboard action, drag-to-dismiss keyboard; existing300ms database/group debounce is preserved.
- **Favourites:** saved count, local search, actionable empty state and stable identity during removal.
- **Appearance:** Follow system / Light / Dark choices persist through SharedPreferences; initial choice follows system.
- **Player:** 48dp dock button,80dp expanded button;160ms reversible play/pause morph.280ms artwork/route expansion and240ms return, with no movement when reduced motion is requested. Group/settings routes use Android's Material/predictive Back transitions.
- **Connection:** visible connecting, paused, live and unavailable states; queue endpoints disable their buttons. A static signal mark avoids recurring ticker work.
- **Transient feedback:** compact floating neutral Snackbar with an appropriate status icon, one message at a time, optional action, horizontal dismissal and accessible content.

## Do's and Don'ts

### Do:
- Do use semantic theme roles and preserve Android system media/notification controls.
- Do keep lazy builders, pagination, keyed items, bounded image decoding and the existing disk cache.
- Do verify native rendering, larger text and performance on real hardware before sign-off.

### Don't:
- Don't crop genre artwork, tint it, zoom it, or decode every group at startup.
- Don't use red hearts or alarming offline banners.
- Don't add decorative perpetual motion, list-wide entrance staggering, blur or shadows to scrolling items.
